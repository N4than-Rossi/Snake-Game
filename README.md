# 🐍 Snake-Game em C++

## 📖 Descrição
Esse projeto é um jogo conhecido como snake game, desenvolvido em C++, no qual você pode controlar uma cobrinha dentro de um campo diretamente no terminal usando os botões do teclado. O usuário pode inicialmente escolher o tamanho do campo e a quantidade de maças, logo após, pode mover a cobrinha pelo mapa com o objetivo de comer as maçãs e crescer.

## 📦 Pré-requisitos

- Compilador C++ instalado (exemplo: GCC)
- Sistema operacional compatível com C++ (Windows, macOS, linux)

## 🚀 Instalação e Execução

1. Clone este repositório: ajeitar aqui depois
   ```sh
   git clone https://github.com/N4than-Rossi/Snake-Game
   ```
   
3. Acesse o diretório do projeto:
   ```sh
   cd Snake-Game
   ```
4. Compile o código-fonte:
   ```sh
   g++ main.c -o snake-game
   ```
5. Execute o programa:
   ```sh
   .\snake-game
   ```

## 🕹️ Como jogar
  1. Execute o programa.
  2. Escolha o tamanho do campo.
  3. Escolha a quantidade de maças.
  4. Se mova para cima, para baixo, para a esquerda e para a direita através das teclas W, S, A e D respectivamente.
  5. Tente crescer o máximo que conseguir.
  6. Escolha se deseja continuar ou sair.
